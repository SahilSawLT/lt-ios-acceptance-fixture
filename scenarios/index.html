Locator stress-test scenarios

Each page is designed to expose a specific class of locator-engine bug.

  • 1. Disambiguation — multiple elements that LOOK like matches
  • 2. Label variants — for=id, nested input, aria-label, aria-labelledby
  • 3. Nested forms — same-role children, nth() targeting
  • 4. ARIA edges — explicit role overrides, aria-label priority
